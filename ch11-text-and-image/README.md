# Chapter 11. Text and image analysis

Corpus diagnostics, classification, topic modelling, and the Green View Index.

## Run it

```bash
pip install -r ../requirements.txt
python image_toolkit.py
```

Or open `notebooks/` in Google Colab, which needs no installation.

## Expected result

English saturates at about 200 labels; the low-resource gap peaks at 0.223 around n = 100.

## Contents

| Path | What it is |
|---|---|
| `*.py` | Analysis module used by the chapter |
| `notebooks/` | Colab-ready walkthrough |
| `data/` | Synthetic sample data with a known answer planted in it |
| `figures/` | The figure printed in the book |
