# Chapter 7. Satellite-based urban analysis

Spectral indices, supervised classification, change detection, and land surface temperature.

## Run it

```bash
pip install -r ../requirements.txt
python rs_toolkit.py
```

Or open `notebooks/` in Google Colab, which needs no installation.

## Expected result

Informal settlements ran 2.55 C hotter than formal built-up areas; NDVI to LST correlation -0.454.

## Contents

| Path | What it is |

| `*.py` | Analysis module used by the chapter |
| `notebooks/` | Colab-ready walkthrough |
