# Chapter 9. AHP, ANP, fuzzy AHP, and IPA

Pairwise comparison, consistency screening, group aggregation, and importance-performance analysis.

## Run it

```bash
pip install -r ../requirements.txt
python build_workbook.py
```

Or open `notebooks/` in Google Colab, which needs no installation.

## Expected result

Consistency screening drops 5 of 25 respondents; skipping it cuts the top weight by 5.4 points.
